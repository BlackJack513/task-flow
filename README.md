# 任务看板 · TaskFlow

一款给个人用的三栏任务看板：**待开始 / 进行中 / 已完成**。所有数据只保存在本机，不联网、不需要账号。

## 安装使用（推荐）

1. 双击 `release\TaskFlow-Setup-1.0.0.exe`。
2. 如果 Windows 弹出 SmartScreen 蓝色提示，点「更多信息」→「仍要运行」。
3. 按提示完成安装。安装到当前用户目录 `%LOCALAPPDATA%\Programs\TaskFlow`，**不需要管理员权限**。
4. 从开始菜单打开「任务看板」。安装程序会尝试创建桌面快捷方式；如果桌面快捷方式打不开，请改用开始菜单。

卸载：Windows「设置」→「应用」→「任务看板」，或开始菜单里的「卸载任务看板」。卸载时默认保留任务数据，方便以后重装。

## 免安装备用

如果不想安装，也可以使用：

1. 把 `release\TaskFlow-1.0.0-portable.zip` 解压到 `Documents` 或任意普通文件夹。
2. 双击解压出来的 `任务看板.exe`。
3. 首次运行如果出现 SmartScreen，点「更多信息」→「仍要运行」。

也可以双击 `release\TaskFlow-1.0.0-localappdata.exe`。它会把程序解压到 `%LOCALAPPDATA%\TaskFlow\app`，不使用系统临时目录。

> 这台电脑的「桌面」文件夹权限有些异常，Chromium 程序放在桌面文件夹里可能无法启动。请使用安装版，或把免安装版放到 `Documents` 等普通文件夹，不要放在桌面。

启动后：

1. 在顶部输入框写下任务，按 `Enter` 或点「添加」。
2. 把任务卡片拖到不同栏；拖进「已完成」会自动记下完成时间。
3. 双击卡片可以编辑标题、备注、切换状态或删除。

安装版和免安装版共用同一份本机数据，数据不会跟着程序文件夹走。

## 已完成越来越多时，怎么展示

这是这个版本最核心的设计：

- 「已完成」按**完成日期**分组，最近的日期排在最上面。
- 今天完成的默认展开；以前每天自动收成一行，例如「11月18日 · 周三 · 7 项」，不会让历史记录淹没当前工作。
- 点日期行可以展开/收起某一天；栏头有「全部展开 / 全部收起」。
- 搜索时会临时展开所有命中的历史分组。
- 已完成区域使用更紧凑的「归档行」，和待开始/进行中的卡片区分开。

## 操作

| 操作 | 方式 |
| --- | --- |
| 快速添加 | 顶部输入框，`Enter` 提交，连续添加时输入框不会失去焦点 |
| 修改任务 | 双击卡片，或悬停卡片后点右上角「⋯」 |
| 移动任务 | 直接拖动卡片到目标栏 / 目标位置 |
| 完成 | 把卡片拖进「已完成」，或用菜单里的「标记完成」 |
| 撤销 | 完成或删除后，点底部提示里的「撤销」 |
| 搜索 | 右上角搜索框，或 `Ctrl + F`；`Esc` 清空 |
| 键盘移动 | 聚焦卡片（Tab）后，`Alt + ← / →` 移动到相邻栏 |
| 新建 | `Ctrl + N` |
| 帮助 | 右上角 `?`，或按 `?` |

## 数据与备份

- 看板数据保存在当前用户目录：`%APPDATA%\taskflow-desktop`。
- 主文件：`taskflow-data.json`；每次保存前会保留上一版 `taskflow-data.backup.json`。
- 如果主文件损坏，程序会自动尝试备份；两份都读不了时，会先另存一份 `taskflow-data.corrupt-<时间>.json`，不会直接覆盖你的原始文件。
- 想手动备份，直接复制数据文件夹里的 `taskflow-data.json` 即可。
- 安装和卸载都不会主动删除这份数据；卸载时如果选择删除，才会一并清理。

## 开发

需要 Node.js 20+ 和 Windows 10/11 x64。

```bash
npm install
npm start
```

重新生成安装包（NSIS 3.04）：

```bash
.artifacts/nsis/Bin/makensis.exe /INPUTCHARSET UTF8 installer.nsi
# 产物：release\TaskFlow-Setup-1.0.0.exe
```

安装包使用 NSIS 编译，源文件为 `installer.nsi`。

技术栈：Electron 30 + 原生 HTML/CSS/JavaScript，无前端框架。窗口、拖拽、本地文件保存都使用 Electron 原生能力。

## 已知说明

- 程序没有接入代码签名证书，所以 Windows 可能显示 SmartScreen 提示。
- 这是单机版：没有云同步、多人协作或账号系统。
- 任务数量上限为 50,000 条，数据文件上限 8 MB，足够个人长期使用。
